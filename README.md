# 🛍️ Responsive E-Store Website

A fully responsive **E-Commerce Store Website** built using **HTML, CSS, and Bootstrap**.  
This project demonstrates a modern shopping website layout with product listings, categories, and a responsive navigation bar.

---

## 🚀 Features
-  Fully responsive design (mobile, tablet, desktop)  
-  Bootstrap-powered grid system  
-  Attractive product cards with hover effects  
-  Shopping categories section  
-  User-friendly navigation bar and footer  
-  Cross-browser compatibility  

---

## 🛠️ Technologies Used
- **HTML5** – Semantic structure  
- **CSS3** – Custom styling  
- **Bootstrap 5** – Responsive grid & components
